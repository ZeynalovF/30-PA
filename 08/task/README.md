# Задание 08. Новый отфильтрованный список

В файле `main.py` выполните задачу.

Создайте функцию `get_positive(values)` с обязательным параметром: списком чисел. Она возвращает новый список только с числами больше нуля. Вызовите функцию для списка с положительными, отрицательными числами и нулём. Покажите исходный список до и после вызова, а также результат.

Фильтрация сохраняет исходный список и возвращает отдельный новый список, даже если подходят все элементы или результат пустой. Сохраните порядок элементов и все повторы. Для пустого исходного списка результат тоже пустой.

## Пример вывода

```text
Before: [-3, 0, 5, 2, -1]
Positive values: [5, 2]
After: [-3, 0, 5, 2, -1]
```
