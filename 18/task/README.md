# Задание 18. Доставка заказа

В файле `main.py` выполните задачу.

Создайте функцию `get_order_total(amount, delivery=5)`. Сумма заказа `amount` обязательна. Функция возвращает сумму заказа вместе с доставкой; обе стоимости неотрицательны и выражены в одной денежной единице. Для одной суммы заказа покажите вызов с обычной доставкой по умолчанию и вызов с бесплатной доставкой. Выведите оба результата.

## Пример вывода

```text
Standard delivery total: 45
Free delivery total: 40
```
