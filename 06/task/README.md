# Задание 06. Использование результата

В файле `main.py` выполните задачу.

Создайте функцию `multiply(first, second)` с двумя обязательными параметрами. Она возвращает произведение чисел. Передайте результат одного вызова аргументом следующего вызова этой же функции и выведите итог вне функции. Можно сохранить промежуточный результат в переменной.

## Пример вывода

```text
Product: 24
```
