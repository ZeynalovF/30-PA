# Задание 21. Товары в наличии

В файле `main.py` выполните задачу.

Создайте функцию `get_in_stock(stocks)` с обязательным параметром: списком складских остатков. Положительное число означает наличие товара, ноль — отсутствие, отрицательное — недостачу. Функция возвращает новый список только положительных остатков. Покажите вызов для смешанного списка, результат и исходный список после вызова.

Фильтрация сохраняет исходный список и возвращает отдельный новый список, даже если подходят все элементы или результат пустой. Сохраните порядок элементов и все повторы. Для пустого исходного списка результат тоже пустой.

## Пример вывода

```text
In stock: [5, 3, 5]
Original stocks: [5, 0, -2, 3, 5]
```
