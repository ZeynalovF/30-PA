# Задание 26. Итоги посещаемости

В файле `main.py` выполните задачу.

Создайте функцию `summarize_attendance(marks)` с обязательным параметром: списком отметок `present` и `absent`. Других отметок нет. Функция возвращает три значения: количество присутствующих, количество отсутствующих и общее число студентов. Для пустого списка все три значения равны нулю. Распакуйте результат вызова в три отдельные переменные и выведите их.

## Пример вывода

```text
Present: 2
Absent: 1
Total students: 3
```
