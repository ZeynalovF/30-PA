# Задание 03. Аргументы по имени

В файле `main.py` выполните задачу.

Создайте функцию `show_dimensions(width, height)` с двумя обязательными параметрами. Она выводит ширину и высоту с понятными подписями. Вызовите её с двумя разными положительными размерами сначала позиционно, затем по имени: аргумент `height` запишите перед `width`. В обоих случаях ширина и высота должны остаться одинаковыми.

## Пример вывода

```text
Width: 8
Height: 3
Width: 8
Height: 3
```
