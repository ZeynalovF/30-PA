# Задание 27. Сводка заказов

В файле `main.py` выполните задачу.

Создайте функцию `summarize_orders(amounts)` с обязательным параметром: списком неотрицательных сумм заказов. Она возвращает количество заказов, общую сумму и средний чек в таком порядке. Средний чек — общая сумма, делённая на число заказов, при отсутствии заказов он равен нулю. Покажите непустой и пустой список: для каждого вызова распакуйте результат в три переменные и выведите их. Округлять возвращаемые значения не требуется.

## Пример вывода

```text
Order count: 3
Total amount: 60
Average order: 20.0
Order count: 0
Total amount: 0
Average order: 0
```
