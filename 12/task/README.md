# Задание 12. Распаковка результата

В файле `main.py` выполните задачу.

Создайте функцию `get_sum_and_difference(first, second)` с двумя обязательными параметрами. Она возвращает сначала сумму чисел, затем разность первого и второго. Распакуйте результат одного вызова в две отдельные переменные и выведите каждое значение с пояснением.

## Пример вывода

```text
Sum: 13
Difference: 5
```
