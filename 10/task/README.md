# Задание 10. Обязательный и необязательный параметры

В файле `main.py` выполните задачу.

Создайте функцию `repeat_text(text, count=2)`. Параметр `text` обязателен. Функция возвращает текст, повторённый `count` раз подряд без добавления разделителей. Количество повторений — неотрицательное число; при нуле результат пустой. Сравните вывод вызова с количеством по умолчанию и вызова с другим количеством для одного текста.

## Пример вывода

```text
Default repeat: HiHi
Three repeats: HiHiHi
```
