# Задание 15. Карточка участника

В файле `main.py` выполните задачу.

Создайте функцию `show_participant(name, team, number)` с тремя обязательными параметрами. Она выводит карточку: имя участника, название команды и номер участника. Вызовите её минимум для двух разных участников. Имена и названия команд задайте на английском, номера — положительными числами.

## Пример вывода

```text
Name: Alex
Team: Falcons
Number: 7
Name: Mia
Team: Owls
Number: 12
```
