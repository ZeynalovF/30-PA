# Задание 11. Пара значений в одном результате

В файле `main.py` выполните задачу.

Создайте функцию `get_double_and_triple(number)` с обязательным параметром. Она возвращает два значения в таком порядке: удвоенное число, утроенное число. Сохраните весь результат одного вызова в одной переменной и выведите содержимое этой переменной.

## Пример вывода

```text
Double and triple: (8, 12)
```
