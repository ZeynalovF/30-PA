# Задание 01. Порядок выполнения

В файле `main.py` выполните задачу.

Создайте функцию `show_step()` без параметров. При каждом вызове она выводит одно и то же короткое сообщение о выполнении шага. Вызовите её дважды. Вне функции добавьте сообщения перед первым вызовом, между вызовами и после второго вызова. По выводу должно быть видно, в каком порядке выполняется программа.

## Пример вывода

```text
Before the first call
Step: running
Between the calls
Step: running
After the second call
```
