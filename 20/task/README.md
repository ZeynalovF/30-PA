# Задание 20. Бонус за активность

В файле `main.py` выполните задачу.

Создайте функцию `add_bonus(scores, bonus=1)`. Обязательный параметр `scores` — список неотрицательных баллов. Функция увеличивает каждый балл в переданном списке на неотрицательный бонус. Верхнего ограничения нет: например, 99 с бонусом 5 становится 104. Измениться должен именно переданный список, использовать возвращённое значение для замены списка не нужно. Покажите список до и после вызова с бонусом по умолчанию, затем вызовите функцию с другим бонусом и снова покажите список. Пустой список остаётся пустым.

## Пример вывода

```text
Before: [2, 99, 5]
After default bonus: [3, 100, 6]
After extra bonus: [8, 105, 11]
```
