# Задание 23. Поиск участника

В файле `main.py` выполните задачу.

Создайте функцию `find_participants(names, prefix)` с двумя обязательными параметрами: списком имён на английском и началом имени. Она возвращает новый список имён, начинающихся с `prefix`, без учёта регистра. Написание найденных имён сохраните таким, каким оно было в исходном списке. Пустое начало подходит ко всем именам. Покажите поиск с разным регистром букв и выведите результат вместе с исходным списком после вызова.

Фильтрация сохраняет исходный список и возвращает отдельный новый список, даже если подходят все элементы или результат пустой. Сохраните порядок элементов и все повторы. Для пустого исходного списка результат тоже пустой.

## Пример вывода

```text
Matching participants: ['Alex', 'ALICE', 'alex']
Original names: ['Alex', 'Mia', 'ALICE', 'Sally', 'alex']
```
