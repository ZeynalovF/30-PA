# Задание 14. Меню учебной программы

В файле `main.py` выполните задачу.

Создайте функцию `show_menu()` без параметров. Она выводит три пронумерованных пункта учебной программы на английском: начать занятие, посмотреть прогресс, выйти. Вызовите её перед началом работы, затем выведите сообщение о завершённом действии и снова вызовите меню. Реализовывать сами действия и выбор пункта не нужно.

## Пример вывода

```text
1. Start lesson
2. View progress
3. Exit
Action completed
1. Start lesson
2. View progress
3. Exit
```
