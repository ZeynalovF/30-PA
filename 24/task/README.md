# Задание 24. Доступные по весу посылки

В файле `main.py` выполните задачу.

Создайте функцию `get_allowed_weights(weights, limit=10)`. Обязательный параметр `weights` — список положительных весов посылок в килограммах. Функция возвращает новый список весов, не превышающих неотрицательный лимит. Покажите результаты с лимитом по умолчанию и другим лимитом для одного списка, затем выведите исходный список.

Фильтрация сохраняет исходный список и возвращает отдельный новый список, даже если подходят все элементы или результат пустой. Сохраните порядок элементов и все повторы. Для пустого исходного списка результат тоже пустой.

## Пример вывода

```text
Up to 10 kg: [2.5, 10, 5]
Up to 5 kg: [2.5, 5]
Original weights: [2.5, 10, 12, 5]
```
