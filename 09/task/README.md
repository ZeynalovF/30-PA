# Задание 09. Фильтрация по параметру

В файле `main.py` выполните задачу.

Создайте функцию `get_short_words(words, max_length)` с двумя обязательными параметрами: списком английских слов и максимальной длиной. Она возвращает новый список слов, длина которых не превышает `max_length`. Максимальная длина — неотрицательное число символов. Для одного списка покажите два вызова с разными ограничениями, дающими разные результаты. Выведите оба результата и исходный список после вызовов.

Фильтрация сохраняет исходный список и возвращает отдельный новый список, даже если подходят все элементы или результат пустой. Сохраните порядок элементов и все повторы. Для пустого исходного списка результат тоже пустой.

## Пример вывода

```text
Up to 3 letters: ['cat', 'go']
Up to 4 letters: ['cat', 'go', 'book']
Original words: ['cat', 'window', 'go', 'book']
```
