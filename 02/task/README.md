# Задание 02. Позиционные аргументы

В файле `main.py` выполните задачу.

Создайте функцию `show_difference(first, second)` с двумя обязательными параметрами. Она выводит разность первого и второго числа. Выберите два разных числа и вызовите функцию позиционно дважды: сначала в одном порядке, затем в обратном. По двум результатам сравните, как порядок аргументов влияет на разность.

## Пример вывода

```text
Difference: 5
Difference: -5
```
