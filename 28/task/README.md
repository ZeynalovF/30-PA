# Задание 28. Отчёт о продажах

В файле `main.py` выполните задачу.

Создайте две функции. `select_sales(amounts, minimum=100)` получает обязательный список неотрицательных сумм продаж и возвращает новый список сумм не ниже неотрицательного порога. `summarize_sales(amounts)` получает обязательный список выбранных сумм и возвращает их количество и общую сумму, для пустого списка оба итога равны нулю. Свяжите вызовы: передайте результат отбора в функцию итогов, затем распакуйте итоги в две переменные и выведите отдельно. Покажите цепочку с порогом по умолчанию и с другим порогом для одного исходного списка, выведите исходный список после вызовов.

Фильтрация сохраняет исходный список и возвращает отдельный новый список, даже если подходят все элементы или результат пустой. Сохраните порядок элементов и все повторы. Для пустого исходного списка результат тоже пустой.

## Пример вывода

```text
Default selected count: 3
Default selected total: 380
Custom selected count: 1
Custom selected total: 180
Original sales: [50, 100, 180, 100]
```
