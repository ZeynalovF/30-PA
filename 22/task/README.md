# Задание 22. Длинные занятия

В файле `main.py` выполните задачу.

Создайте функцию `get_long_lessons(durations, minimum=80)`. Обязательный параметр `durations` — список неотрицательных продолжительностей занятий в минутах. Функция возвращает новый список занятий длительностью не меньше `minimum`. Порог неотрицателен. Для одного списка покажите результаты с порогом по умолчанию и другим порогом, а также исходный список после вызовов.

Фильтрация сохраняет исходный список и возвращает отдельный новый список, даже если подходят все элементы или результат пустой. Сохраните порядок элементов и все повторы. Для пустого исходного списка результат тоже пустой.

## Пример вывода

```text
At least 80 minutes: [80, 100, 90]
At least 90 minutes: [100, 90]
Original durations: [60, 80, 100, 90]
```
