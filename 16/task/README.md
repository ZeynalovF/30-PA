# Задание 16. Цена билетов

В файле `main.py` выполните задачу.

Создайте функцию `get_ticket_total(price, visitors)` с двумя обязательными параметрами: ценой одного билета и числом посетителей. Она возвращает общую стоимость билетов. Цена неотрицательна, посетителей может быть ноль. Для одной цены получите стоимость двух групп разного размера, выведите обе суммы и сообщите, для какой группы посещение дороже или что стоимости равны.

## Пример вывода

```text
First group total: 36
Second group total: 60
The second group costs more
```
