# Задание 04. Три обязательных параметра

В файле `main.py` выполните задачу.

Создайте функцию `show_card(name, age, hobby)` с тремя обязательными параметрами. Она выводит имя, возраст и увлечение. Вызовите функцию: имя передайте позиционно, возраст и увлечение — по имени. Возраст задайте положительным числом полных лет, имя и увлечение напишите на английском.

## Пример вывода

```text
Name: Alex
Age: 18
Hobby: chess
```
