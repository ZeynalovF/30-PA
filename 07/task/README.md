# Задание 07. Возврат из ветвей

В файле `main.py` выполните задачу.

Создайте функцию `get_sign(number)` с обязательным параметром. Она возвращает `positive` для числа больше нуля, `negative` для числа меньше нуля и `zero` для нуля. Вызовите её для всех трёх случаев и выведите результаты вне функции.

## Пример вывода

```text
Sign of 4: positive
Sign of -2: negative
Sign of 0: zero
```
