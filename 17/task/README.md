# Задание 17. Перевод времени

В файле `main.py` выполните задачу.

Создайте функцию `to_minutes(hours, minutes)` с двумя обязательными параметрами. Она возвращает общее число минут. Часы неотрицательны, минутная часть — от 0 до 59; длительности заданы в полных минутах. Получите длительности двух занятий через вызовы функции, выведите их и по возвращённым результатам сообщите, какое занятие длиннее или что длительности равны.

## Пример вывода

```text
First lesson minutes: 80
Second lesson minutes: 90
The second lesson is longer
```
