# Задание 25. Покупка в автомате

В файле `main.py` выполните задачу.

Создайте функцию `check_payment(price, paid)` с двумя обязательными параметрами: ценой товара и внесённой суммой. Обе суммы неотрицательны. Она возвращает сначала признак достаточной оплаты (`True` или `False`), затем сдачу. Если денег хватает, сдача равна внесённой сумме за вычетом цены, при нехватке денег сдача равна нулю. Покажите достаточную и недостаточную оплату: в каждом случае распакуйте результат в две переменные и выведите их.

## Пример вывода

```text
Payment accepted: True
Change: 3
Payment accepted: False
Change: 0
```
