# Задание 19. Печать копий

В файле `main.py` выполните задачу.

Создайте функцию `get_print_cost(pages, copies, price=0.1)`. Число страниц в одной копии `pages` и число копий `copies` обязательны. Функция возвращает стоимость печати всех копий, где `price` — цена одной страницы. Количество страниц и копий неотрицательно, цена тоже, нулевое количество даёт нулевую стоимость. Покажите и подпишите результаты вызовов с ценой по умолчанию и с другой ценой. Округлять возвращаемое значение не требуется.

## Пример вывода

```text
Default printing cost: 3.0
Custom printing cost: 6.0
```
