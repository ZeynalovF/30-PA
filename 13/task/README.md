# Задание 13. Три значения из функции

В файле `main.py` выполните задачу.

Создайте функцию `describe_numbers(values)` с обязательным параметром: непустым списком чисел. Она возвращает количество чисел, их сумму и среднее в указанном порядке. Среднее — сумма, делённая на количество. Распакуйте результат одного вызова в три переменные и выведите их с пояснениями. Пустой список в этой задаче не передаётся.

## Пример вывода

```text
Count: 3
Total: 21
Average: 7.0
```
